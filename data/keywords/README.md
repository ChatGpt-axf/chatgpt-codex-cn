# Keyword Imports

Keyword files use UTF-8 CSV with these columns: `keyword`, `primary_keyword`, `cluster`, `intent`, `priority`, `target_url`, and `status`.

Import is a planning step, not a page generator. Group rows by the same search intent and expected answer. Use `status=merged` when a variant belongs to an existing target page. A new target URL is justified only when the search task, answer, and useful page structure are materially different.
